# 📘 Sistema de Servicios Escolares – CBTIS 239

Sistema integral para la gestión de procesos académicos y administrativos del **Centro de Bachillerato Tecnológico Industrial y de Servicios No. 239 (CBTIS 239)**, desarrollado como proyecto de la asignatura **Fundamentos de Ingeniería de Software**.

---

## 📌 Descripción general

Este proyecto tiene como objetivo **digitalizar y optimizar los procesos del Departamento de Servicios Escolares**, centralizando la información estudiantil y automatizando tareas clave como la inscripción, credencialización, control de asistencia, gestión académica y generación de reportes.

El sistema mejora la **eficiencia operativa**, garantiza la **trazabilidad de la información** y refuerza la **seguridad de los datos**, reduciendo errores derivados de procesos manuales.

## 🧱 Arquitectura del sistema

El sistema implementa una **arquitectura monolítica en capas**, compuesta por:

- Capa de presentación (JavaFX)  
- Controladores  
- Lógica de negocio (BO)  
- Acceso a datos (DAO)  
- Base de datos MySQL  

Esta estructura facilita el mantenimiento, la escalabilidad y la correcta separación de responsabilidades.

## 📂 Funcionalidades principales

- Inscripción y reinscripción de alumnos  
- Generación automática de matrícula  
- Expediente académico digital unificado  
- Credencialización con código de barras  
- Registro de asistencia por escaneo  
- Historial de asistencias con justificación  
- Gestión de calificaciones por docente  
- Asignación de materias, grupos y horarios  
- Generación de reportes en PDF  
- Bitácora de auditoría  
- Administración de usuarios y roles
